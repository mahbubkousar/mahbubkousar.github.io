Physics Chatbot via RAG + Local LLMs

A physics tutor that works offline, because the laws of motion should not require Wi-Fi.

Educational AIOffline RAGLocal LLMs

This project is an offline RAG-based physics tutor designed to answer conceptual, formula-based, and numerical questions with cited sources. It combines semantic retrieval with locally hosted language models, making the system useful in settings where network dependence is undesirable or simply impolite.

Retrieval
FAISS semantic search over a 562-vector knowledge base.
Models
Locally hosted LLMs including Llama 3.2 and Phi-3.
Interface
Streamlit UI with LaTeX-rendered responses.

Retrieval Design

The system retrieves relevant curriculum material using FAISS before generating an answer. This keeps responses anchored to source content and reduces the model's opportunity to hallucinate a new branch of physics.

Performance Observation

Retrieval latency reached approximately 10ms across the knowledge base, making the tutor fast enough for interactive use. The real pedagogical challenge then becomes answer quality, not waiting for the system to remember Newton.

Evaluation

Retrieval accuracy and answer relevance were evaluated across multiple curriculum difficulty levels. The result is a practical tutor prototype aimed at traceable explanations rather than mysterious oracle behavior.
