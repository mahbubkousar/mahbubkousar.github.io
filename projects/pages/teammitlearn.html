TeammitLearn

An interactive physics simulator where parameters move faster than excuses.

Interactive SimulationThree.jsEducational AI

TeammitLearn is a Three.js-based interactive physics simulation platform for real-time projectile and motion modeling. It combines direct visual feedback with an LLM-controllable simulation API, because sometimes the best interface is "make gravity weird and explain what happened."

Renderer
Three.js real-time visual simulation pipeline.
Controls
Adjustable gravity, velocity, angle, and related physical parameters.
AI Layer
Natural-language parameter control and AI-generated practice questions.

Simulation Design

The platform models motion in real time, allowing students to modify parameters and immediately observe the consequences. This makes abstract formulas visible, which is useful when equations are being technically correct but emotionally unhelpful.

LLM Control

The simulation exposes an API that can be controlled by language-model instructions. Users can describe parameter changes naturally, and the system maps those requests into simulation updates.

Practice Generation

AI-generated practice questions connect the simulation state to learning tasks. The result is an environment that can demonstrate a concept and then immediately ask whether the learner was paying attention.
