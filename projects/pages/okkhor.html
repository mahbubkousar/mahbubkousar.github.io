Okkhor

A Bengali programming language prototype, because syntax should occasionally speak back in Bangla.

Programming LanguageCompilerBengali Script

Okkhor is a Bengali-language programming language prototype implemented in Python. It explores what a native Bengali-script programming grammar can look like when treated as a real language design problem rather than a novelty label pasted onto English syntax.

Frontend
Custom lexer, parser, and AST generator.
Backend
Bytecode compiler and stack-based virtual machine.
Coverage
Unit tests for language components and VM behavior.

Language Design

The grammar defines Bengali-script tokens for variables, control flow, and function declarations. The design goal is not merely translation, but a coherent programming surface shaped around Bengali notation.

Compiler Pipeline

Source code is tokenized, parsed into an AST, compiled into bytecode, and executed on a stack-based virtual machine. This makes Okkhor a compact end-to-end language implementation rather than a parser demo wearing a graduation cap.

Research Value

The project sits at the intersection of programming language tooling and language accessibility. It is a small prototype, but it asks a useful question: what would local-language computing feel like if the compiler met the user halfway?
