TeammitDrive

Natural-language file search for people who know the document exists, somewhere, probably.

RAG-Based File SearchTelegram BotCloud Storage

TeammitDrive is a RAG-based Telegram bot that lets users search files across aggregated storage providers through natural language. It targets the common tragedy of remembering what a file was about but not what it was called.

Providers
Google Drive, Dropbox, OneDrive, and similar connected storage options.
Interface
Telegram bot conversation flow.
Ranking
Embedding-based semantic ranking over file metadata.

Unified Retrieval Layer

The system unifies multiple cloud storage APIs behind one retrieval layer. Users can ask for files across connected accounts without manually checking each storage service like a digital archaeologist.

Semantic Ranking

Embeddings are applied to file metadata so search can surface relevant results beyond exact filename matches. This makes the system more tolerant of human memory, which is generous because human memory started the problem.

Conversational Access

Telegram provides a low-friction access point for querying files from a chat interface. The design favors direct natural-language requests over making users learn yet another search syntax.
