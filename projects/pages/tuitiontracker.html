TuitionTracker

An Android app for turning tuition logistics into something less notebook-dependent.

Android ApplicationKotlinFirebase

TuitionTracker is a native Android tuition-management application for attendance tracking, payments, analytics, and notifications. It targets the practical administrative work around tutoring, where the real enemy is not complexity but forgetting who paid when.

Client
Kotlin, Jetpack Compose, and MVVM architecture.
Backend
Firebase and Firestore with owner-scoped access rules.
Features
Attendance, payments, analytics dashboards, and automated notification scheduling.

Application Model

The app models students, attendance sessions, payment status, and dashboard summaries. The interface is built for repeated operational use rather than one-time novelty, which is usually where prototypes start sweating.

Data and Access

Firestore provides shared persistence, while owner-scoped rules protect user-specific data. This keeps the convenience of a cloud backend without treating every tutor's records as a public group project.

Analytics

Real-time dashboards summarize attendance trends and payment state across students. The result is a practical reporting layer that replaces guesswork with a slightly more civilized form of accountability.
